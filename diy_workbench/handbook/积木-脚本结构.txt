ls_program|把一张卡完整的 Lua 程序拆成可编辑的树，统管初始化、函数和提示文字。|先在练习卡用「脚本积木 → 从 MDPro3 实卡读取」导入强欲之壶，展开初始化函数，找哪一步登记了抽卡效果。|逐函数阅读。要回去修改原来的中文效果，可在同一菜单还原上次转换。
ls_function|给一串步骤取一个名字，以后引擎或别的函数可以调用它。|展开 s.initial_effect，参数 c 表示正在初始化的卡。找到它创建并登记效果的语句。|定义不会自动在任意时候运行。普通自建函数还要被调用或登记为回调。
ls_local_function|定义一个只在当前这一段代码内可见的小函数。|局部函数名写 double，参数 n，内部「返回值」放 n 乘2，再在同一范围调用 double(3) 应得6。|在局部函数定义所在范围之外不能按这个名字调用。
ls_local|给临时保存的值起名字。|变量名填 n，在「值」接数字常量2，再在后面用「变量或引擎常量」读 n。|读值前先声明，拼写和大小写须一致。
ls_assign|给已经确定的变量或表里的某一项换一个值。|先声明 n 为2，再将写入目标设 n，值设 n 加1，最后应为3。|左边要能写入，例如变量或表项。固定数字不能作为写入目标。
ls_run|按程序顺序实际执行放进槽里的那次调用。|在处理函数「依次执行」放本块，调用槽接「让玩家抽卡」，参数用 tp、1、REASON_EFFECT。|创建函数或取得函数名只得到一个值。要执行才会进行操作。
ls_if|先检查一个条件，成立才执行里面的语句。|条件放 n 大于0，里面执行抽卡。让 n 分别取0和1，观察分支。|Lua 中0也算真，需要比较 n>0 才能判断正数。
ls_elseif|当上面的分支未成立时，继续检查第二个条件。|在「如果条件成立」的其他分支放本块，首项比 n>3，第二项比 n>0。n为2应走第二项。|分支按顺序取第一个成立项，把更具体的判断放前面。
ls_else|在前面所有条件都不成立时执行备用步骤。|在如果的最后放本块，前面检查是否有目标，落入否则时直接返回。|它不需要条件。同一个如果只应有一个最后的否则。
ls_for|用一个计数变量从起点走到终点。|变量 i，起点1、终点3、步长1。每轮把 i 加入总和，结果为6。|默认步长1。倒着数时写负数，避免起终方向和步长冲突。
ls_for_in|逐个读取迭代器交出的卡片或数据。|变量 tc，迭代器接 aux.Next(g)，循环体里读取 tc 的攻击力，g中两张卡会处理两轮。|先让 g 成为卡片组，空组不会执行循环体。
ls_while|每一轮先问条件，成立才做下一轮。|先声明 n=3，条件 n>0，循环体写 n=n-1。共做三次。|循环内必须能让条件变假。练习先用小数值确认会停止。
ls_repeat|先做一轮，再检查是否达到停止条件。|先让 n=0，循环体增加1，停止条件 n>=2，应执行两轮。|这里判断的是何时停止。哪怕起初满足条件，循环体也会先执行一次。
ls_scope|用一对边界把临时变量局限在一个小段中。|在本块内声明临时变量 tmp，后续计算也放在块内。|如果离开这段后还要用结果，在外层先声明变量，再在里面赋值。
ls_break|立刻退出最近包住它的那一层循环。|遍历卡片组时，当找到第一只合格怪兽便在「如果」中放本块。|本块须处在循环内。想离开整个函数应使用「返回值」。
ls_return|把结果交还给调用者，同时结束当前函数。|在名叫 ok 的筛选函数中返回「这张卡是龙族」的判断，调用者得到真或假。|把返回放在该分支最后。需要继续执行的动作应写在返回之前。
ls_label|给同一段程序中的一个位置命名，供跳转使用。|在读取含 goto 的旧卡时，找到名字相同的 label 并从那里继续跟读。|新手做分支可直接用「如果」。标签名拼错会找不到落点。
ls_goto|让执行位置跳到指定名字的标签。|读旧脚本时从 goto done 找到本函数内的 done 标签，检查两者之间跳过了哪些步骤。|跳转不能闯入尚未生效的局部变量范围。向前反复跳也可能无法停止。
ls_name|引用已存在的变量名或游戏提供的常量。|在抽卡调用的玩家槽放 tp，在原因槽放 REASON_EFFECT。|这里写变量名原样，不加引号。若需要显示文字，应选「文本常量」。
ls_number|给脚本提供一个数字字面值。|在抽卡的「张数」放1。读编号时十六进制0x10等于十进制16。|写数字本身，不加引号，也不要把中文单位写进框。
ls_string|提供一段文本值，Lua 用引号标明文字的起止。|在表项值填 "练习完成"，需要显示时再交给接受文本的函数。|用配对的半角引号。屏幕提示如要求提示编号，改用对应的提示接口。
ls_atom|提供真假、空值或可变参数这类特殊值。|条件函数简单返回 true 或 false。函数要求「没有排除卡」时可传 nil。|字符串 "false" 是文字，在 Lua 判断里仍为真。
ls_binary|用一个运算符把左右两个值组合成结果。|左侧放 n，选 >=，右侧放2，就能在「如果」中判断 n 是否至少2。|=用于赋值，Lua 的相等比较写==。左右类型也要符合运算。
ls_unary|只对一个值做操作，例如判断不成立或取长度。|在单项运算选 not，输入 false，结果为 true。|长度符号用于字符串或可计数对象。不会自动把数字当张数清单。
ls_parens|保留括号分组，并可把多返回值缩为第一个值。|对比 GetID() 与 (GetID()) 赋给两个名字时的差异，后者只给出第一个结果。|读实卡初始化时保留原括号位置，多返回值丢失会让后续卡号为空。
ls_member|从表或对象按固定成员名读取一项。|对象填 s，名称填 operation，表示 s.operation，可把它交给设置处理函数的槽。|取函数本身时不加调用括号。立刻执行是另一种操作。
ls_index|通过一个计算出来的键在表中找值。|已有表 t，把对象设 t，索引放数字1，即读 t[1]。|数字1与文本"1"是两种键，读不到时先对照建表时写的键。
ls_call|把一个函数值和参数组合成一次普通调用。|函数选「按名称读取成员」Duel.Draw，参数依次放 tp、1、REASON_EFFECT。|要产生动作时再接「执行函数或对局操作」。参数顺序照接口。
ls_method|调用属于某张卡、某个效果或某组卡的方法。|对象放 c，名称 GetAttack，得到 c:GetAttack() 的攻击力。|冒号调用会带上对象本身，参数里不用再重复塞一个 c。
ls_lambda|在当前位置临时建立一个可传给其他函数的回调。|给筛选函数槽放本块，参数 tc，内部返回 tc 是否符合所需卡种。|回调里要把判断结果返回。只计算条件而不返回会被当成没有结果。
ls_table|把多项资料装进一张 Lua 表，可以按下标或名字查。|先放两个「列表元素」值10和20，用第二项的下标2读出20。|表、引擎卡片组是不同种类。需要卡片组的方法时先确认对象类型。
ls_item|给表追加一个按顺序排列的元素。|在「建立一张表」里先加值10，再加值20。没指定键时顺序从1开始。|中间的空值可能使长度计算不直观，起步练习先用连续数字。
ls_named_field|为表中的一项设置固定名称。|在表里名称填 count、值填2，然后读取 t.count。|名称跟读取时大小写相同。动态算出来的键改用「按键写入表项」。
ls_key_field|用一个表达式作表项的键，再关联一个值。|键放数字42，值放文本"龙"，之后读取 t[42]。|给错了字符串键"42"会查不到数字键42的资料。
ls_hint|给模拟器中出现的询问或效果选项写一条可显示的提示。|在整卡脚本的提示槽填序号0、文字「是否抽1张」，并在效果说明引用相同序号。|提示文字只是给人看，不会自己抽卡。序号要和引用一致。
ls_engine|从本机的接口手册选一个没有专用积木的引擎调用。|搜「回合玩家」选 Duel.GetTurnPlayer，返回目前行动的一方，再与 tp 比较。|看签名所需参数。像「谁的回合」这样的常见设计也能直接用中文条件积木。
