# blocks：v0.3 真积木

设计见 `effect_model/docs/v0.3-积木设计.md`。积木贴近引擎，文本做辅助；界面是缩进列表 + 拖拽。
DIY 工作台的「效果」页用的就是这里（存档只存 v0.3 积木树，旧的 v0.2 存档第一次读到时自动转换）。

| 文件 | 内容 |
| --- | --- |
| `__init__.py` | `build(model)` → `{"lua", "desc", "pdesc", "strings", "issues"}`，和 `effect_model.build` 一样；导出（ygopack）按 schema 分派 |
| `catalog.py` | 积木目录（208 块）：类型、选项、槽（`(名字, 中文, 接受的类型, 能放几块, 只收哪些积木)`）、列表里显示的字 |
| `effect_codes.json` | 引擎的 259 种效果代码（中文取自常量表注释，分 12 类，常用 49 种在前）；`build_codes.py` 重新生成 |
| `compile.py` | 积木树 → 萌卡一系 Lua：逐块翻译；能否发动的检查、处理预告、效果分类、提示文字由积木自动算出；召唤手续沿用 v0.2 的生成代码 |
| `read.py` | 积木树 → 中文：每块有自己的读法；认得出的常见拼法换成官方说法；灵摆效果分开 |
| `convert.py` | 旧存档（v0.2）→ 积木树：换不了的部分变成「自定义 Lua」积木并列出说明，原存档留在 `legacy_v02` |
| `check_proto.py` | 四十二张样例卡的文字、沙盒情景、改坏一处的对照（写出 `samples/`）；另有 41 张卡把每个时机、每种次数和新积木都拼进去，要能读成中文、被引擎加载 |
| `coverage.py` | 积木能复现多少官方卡：逐个扫 MDPro3 的官方卡脚本，等价写法算已覆盖，拼不出的按类别统计，写 `覆盖统计.md`；`抽查记录.md` 是人工抽查 30 张的结果 |
| `check_convert.py` | effect_model 的 46 张 v0.2 样例卡逐张转换、生成、引擎加载，汇总没能完全转换的地方 |

界面在 `diy_workbench/block_editor.py`（工作台里嵌入使用；`block_proto.py` 可以单独打开）。

```
python -m blocks.check_proto                 # 样例卡的检查
python -m blocks.check_convert               # 旧存档转换
python -m blocks.coverage                    # 官方卡覆盖统计（写 blocks/覆盖统计.md）
./_tools/run.ps1 block_proto.py              # 单独打开积木编辑器窗口（PowerShell）
./_tools/run.ps1 block_editor_test.py        # 编辑器的往返、放置规则、撤销、嵌入模式
./_tools/run.ps1 workbench_test.py           # 工作台整体：旧存档转换、拼积木、写回、导出
```

词汇统计 50.1% → 74.1%，人工抽查约 75% 真能拼，实际约 55%（`抽查记录.md`）。
