# 从源码运行和构建

已验证的目标环境为 64 位 Windows、Python 3.12 和 `requirements-build.txt` 中的依赖版本。

请在纯英文目录创建构建环境，例如 `D:/YGODIY`。Qt 5 的路径编码问题会影响位于中文目录的虚拟环境，详见 [PyInstaller 上游记录](https://github.com/pyinstaller/pyinstaller/issues/7385)。源码运行和构建产物的插件查找已使用实际安装路径。

## 获取源码和依赖

```powershell
git clone https://github.com/YYY-ZSJ/YGODIY.git
cd YGODIY
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
```

只运行源码时可以安装 `requirements.txt`。构建环境增加 PyInstaller，桌面程序本身的依赖共用同一份清单。

## 准备运行资源

```powershell
.\.venv\Scripts\python.exe scripts/prepare_resources.py
```

脚本从本仓库的 `build-resources-v1` Release 下载资源包，缓存到 `.cache/`，核对 ZIP 的 SHA-256，再按 `resources-manifest.json` 逐个校验并放入 `resources/`。下载约 1.56 GiB，准备环境和构建时请预留 6 GB 磁盘空间。

资源包括 `mold`、`CardBack`、`Field_Center`、`Past_Version`、`Rush_Duel`、五份默认卡面配置，以及本地翻译模型和推理文件。完整文件列表和每个文件的校验值均在清单中。

已经下载 ZIP 时可以离线准备。

```powershell
.\.venv\Scripts\python.exe scripts/prepare_resources.py --archive "D:\下载\YGODIY-build-resources-v1.zip"
```

已有完整程序目录时，可以直接导入同版本资源。

```powershell
.\.venv\Scripts\python.exe scripts/prepare_resources.py --from "D:\软件\YGODIY_2.1.0"
```

导入按清单逐个读取并校验。资源版本不符时会列出失败文件，请改用本仓库提供的 ZIP。

## 启动源码

```powershell
.\.venv\Scripts\python.exe main.py
```

默认运行资源位于仓库的 `resources/`。设置、AI 会话、日志和离线卡库位于 `data/`。可以通过 `YGODIY_RESOURCES` 和 `YGODIY_APP_DIR` 分别指定资源目录和用户数据目录。

## 构建独立程序

```powershell
.\.venv\Scripts\python.exe scripts/build.py
```

脚本先校验全部资源，再运行 `YGODIY.spec`。构建结果位于 `dist/YGODIY/`，入口为 `YGODIY.exe`。整个文件夹包含解释器、Qt 插件、Python 依赖和资源，可以复制到其他 64 位 Windows 电脑运行。

PyInstaller 在 Windows 上生成 Windows 程序。构建方式和资源收集机制见 [PyInstaller 官方说明](https://pyinstaller.org/en/stable/spec-files.html)。

## 离线卡库

首次运行即可制作 DIY 卡。需要按官方卡名查卡时，下载百鸽卡片资料。

```powershell
.\.venv\Scripts\python.exe scripts/update_cards.py
```

需要全部卡图或卡包编号时，分别添加 `--images` 或 `--packs`。批量卡图下载体积较大。默认输出到 `data/离线卡库/`，`--output` 可以指定其他目录。

## MDPro3 沙盒和安装

测试沙盒及一键安装依赖 MDPro3。安装 MDPro3 后，可使用现有自动查找或手动指定安装位置。

```powershell
$env:YGODIY_MDPRO3 = "D:\游戏\MDPro3"
.\.venv\Scripts\python.exe main.py
```

沙盒会读取 MDPro3 的 `MDPro3_Data/Plugins/x86_64/ocgcore.dll`、`Data/script.zip` 和 `Data/locales/zh-CN/cards.cdb`。AI 助手的服务设置在首次使用时由用户填写。

## 排错

- 缺少 `config/config.json` 或卡框时，重新运行资源准备脚本，再运行 `--check` 核对清单。
- 提示找不到 PyQt5 等模块时，确认命令使用 `.venv/Scripts/python.exe`，并重新安装依赖清单。
- 翻译模型缺失或无法加载时，查看 `data/制卡器标签页.log` 中的翻译记录。
- 沙盒提示缺少 MDPro3 文件时，核对安装目录和以上三份运行文件。
