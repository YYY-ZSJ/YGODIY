# YGODIY

YGODIY 是一个 Windows 桌面的游戏王 DIY 工具：做卡面、用积木写效果、生成脚本、测试，再打包装进 MDPro3，都在一个程序里完成。不会编程也能用，内置的 AI 助手伊格尼斯可以帮你设计效果和写脚本。

> 本项目是玩家自制的非官方工具，与 Konami 及游戏王官方没有任何关系。

## 能做什么

**制作卡面**

| 模式 | 用途 |
| --- | --- |
| OCG/TCG | 标准卡面，支持灵摆、连接、超框卡图、罕贵度、防伪和版权样式 |
| 超速决斗（Rush Duel） | RD 卡面，支持日文注音 |
| 场地中心卡、卡背 | 场地中心卡和卡背 |
| 旧版卡、漫画卡 | 老式卡框和漫画风格卡面 |

**DIY 工作台**

- **积木写效果：** 拼积木就能写效果，程序会把它读成官方风格的中文效果文字，并生成 Lua 脚本。
- **测试沙盒：** 用 ygopro-core 对局引擎实际加载并运行这张卡，按设定的情景检查效果。
- **脚本页：** 也可以直接写 Lua，有行号、高亮、补全、参数提示和接口手册。
- **导入导出：** 支持 `.ydiy` 和 `.ypk`，可以导出单张卡或整个卡包。
- **MDPro3：** 一键把卡包装进 MDPro3，也支持立绘、超框卡图、动态卡图和同名卡。「已安装」页可以管理卡包，卸载的卡包进回收站，能恢复。

**伊格尼斯（AI 助手）**

在任意模式都能打开。它可以设计效果文字、拼积木、写 Lua、跑测试。它的修改先作为候选给你看，由你决定是否应用；删除、导出和安装前也会向你确认。

## 安装和运行

这个仓库只有**源码**。程序还需要运行环境和资源（Python 3.12、PyQt5、卡面素材、字体、离线卡库等），这些文件体积很大，部分素材也不适合公开分发，所以没有放进仓库。只下载源码无法直接运行。

有完整程序目录的话，把本仓库放到程序目录 `YGODIY_2.1.0` 旁边，文件夹命名为 `YGODIY_src`，再运行程序目录里的 `启动YGODIY.bat` 即可使用这份源码。目录结构和开发细节见 [源码说明](docs/源码说明.md)。

## 快速上手

### 做一张卡面

1. 在窗口顶部的下拉框选择模式，比如 `OCG/TCG`。
2. 在右侧填写卡名、类型、属性、攻守和效果文字，导入卡图。
3. 左侧的「卡包」「卡片」列表用来管理多张卡。

### 写效果并装进 MDPro3

1. 模式切换到 **DIY 工作台**，选中一张卡。
2. 在「效果」页拼积木，程序会生成效果文字。积木表达不了的效果，可以到「脚本」页手写 Lua，或者点「让伊格尼斯写」。
3. 点「在测试沙盒里检查这张卡」，确认效果能运行。
4. 到「卡包」页检查卡号和字段，点「导出并装进 MDPro3」。如果只要文件，点「只导出 .ypk 文件…」。
5. 想卸载或恢复卡包，到「已安装」页操作。

### 复制或导出卡片文字

- **OCG/TCG、超速决斗模式：** 点顶栏的「复制文字」复制当前卡；点旁边的小箭头可以导出 txt。
- **DIY 工作台：** 在「卡包」页点「导出文字」，可以导出这张卡或整个卡包。

导出格式：

```text
卡名
[怪兽|效果|调整] 电子界/风
[★3] 600/1000

效果文字
```

### 使用伊格尼斯

1. 点顶栏的「伊格尼斯」打开面板。
2. 在服务设置里选择服务商，填入你自己的 API Key。
3. 用文字描述想要的卡，比如「帮我设计一张从卡组检索的魔法卡」。
4. 查看它给出的修改，确认后应用；不满意可以撤销。

内置的服务商有 DeepSeek、Grok、Kimi、通义千问、硅基流动、智谱 GLM、OpenAI、Claude 和本地 Ollama，也可以填自定义服务。使用云端服务的费用由服务商收取；开始对话后，你的卡片内容和对话会发送给所选的服务商。API Key 用 Windows 的数据保护接口加密后保存在本机。

## 目前的限制

- 积木还不能表达所有效果，复杂的卡需要手写 Lua 或让伊格尼斯兜底。
- 通过测试沙盒不代表效果完全正确，重要的卡请在实际对局里再试一次。
- 伊格尼斯写的内容要自己核对，尤其是效果文字和裁定细节。
- 只支持 Windows。
