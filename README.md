# YGODIY

YGODIY 4.1.0 是一款游戏王 DIY 桌面工具。你可以制作卡面、用积木拼效果、生成 Lua 脚本，随后在 MDPro3 中试牌。第一次接触游戏王或编程，可以从「积木入门」开始。

> 本项目是玩家自制的非官方工具，与 Konami 及游戏王官方没有任何关系。

## Windows 桌面版

**4.1.0 完整离线安装包（64 位 Windows）** 内置主程序和原 4.0.0 的全部 14,275 张高清卡图。GitHub 提供两个分卷，请把两卷下载到同一文件夹，用 7-Zip 或 WinRAR 打开第一卷，解压出 `YGODIY_4.1.0.exe`（3.29 GiB）。双击即可离线安装，转发给朋友时只需发送这一个 EXE。[下载分卷一](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY_4.1.0-Full.7z.001) · [下载分卷二](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY_4.1.0-Full.7z.002) · [SHA-256 校验文件](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY_4.1.0-Full.sha256)

另有较小的安装向导（1.38 GiB），安装时会联网下载图库。也可事先把原图库 ZIP 与它放在同一文件夹，保留原名后离线安装。完整安装约占 3.62 GiB。[小型安装向导](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY-4.1.0-Windows-x64-Setup.exe) · [单独下载原图库](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY-4.1.0-HD-Art.zip)

也可以使用[便携版主程序 ZIP](https://github.com/YYY-ZSJ/YGODIY/releases/download/v4.1.0/YGODIY-4.1.0-Windows-x64.zip)。先完整解压程序，再把高清原图库 ZIP 解压到 `YGODIY.exe` 所在目录，卡图会落在 `离线卡库/卡图/`。这一套与原 4.0.0 的 14,275 张卡图逐文件一致。程序内含 Python、卡框、字体、本地翻译模型和离线卡片文字库。

从 4.0.0 迁移自己的卡包时，先关闭旧版。在首次启动新版前，将旧目录里的 `制卡器标签页.json` 和 `制卡器标签页资源` 一起复制到新版 `YGODIY.exe` 旁，即可继续编辑原有卡包。

## 安卓横屏版

[下载安装包](https://github.com/YYY-ZSJ/YGODIY/releases/tag/android-v1.0.0) · [安卓源码和构建说明](android/)

Android 10 及以上可离线制作卡面、管理卡包、用 240 种积木编写中文效果。界面沿用 4.0.0 的双列表、模式下拉框和工作台三栏。

## 能做什么

**制作卡面**

| 模式 | 用途 |
| --- | --- |
| OCG/TCG | 标准卡面，支持灵摆、连接、超框卡图、罕贵度、防伪和版权样式 |
| 超速决斗（Rush Duel） | RD 卡面，支持日文注音 |
| 场地中心卡、卡背 | 场地中心卡和卡背 |
| 旧版卡、漫画卡 | 老式卡框和漫画风格卡面 |

**DIY 工作台**

- **积木写效果**　把条件、代价、对象和处理拼起来，工作台会生成中文效果文字和 Lua 脚本。也可以从 MDPro3 或本地 `.lua` 读取整卡脚本，在积木里修改。
- **测试沙盒：** 用 ygopro-core 对局引擎实际加载并运行这张卡，按设定的情景检查效果。
- **脚本页：** 也可以直接写 Lua，有行号、高亮、补全、参数提示和接口手册。
- **卡包管理**　卡片和卡包支持拖动排序。可以按名称查找字段、指示物，也可以新建或修改自定义编号。
- **导入导出**　`.ydiy` 用来交换可继续编辑的制卡工程，`.ypk` 用来分发带脚本和图片的游戏扩展，独立 `.cdb` 用来交换卡片资料和文本。
- **MDPro3：** 一键把卡包装进 MDPro3，也支持立绘、超框卡图、动态卡图和同名卡。「已安装」页可以管理卡包，卸载的卡包进回收站，能恢复。

**伊格尼斯（AI 助手）**

在任意模式都能打开。它可以设计效果文字、拼积木、写 Lua、跑测试。它的修改先作为候选给你看，由你决定是否应用；删除、导出和安装前也会向你确认。

## 从源码运行和构建

在 **64 位 Windows 和 Python 3.12** 下，可以从仓库准备运行环境并构建独立程序。首次准备会下载约 1.56 GiB 的运行资源，包含卡框、字体、默认配置和本地翻译模型。

构建环境请放在纯英文路径，例如 `D:/YGODIY`。在该位置打开 PowerShell，运行下面的命令。

```powershell
git clone https://github.com/YYY-ZSJ/YGODIY.git
cd YGODIY
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe scripts/prepare_resources.py
.\.venv\Scripts\python.exe main.py
```

构建独立程序时运行下面的命令，结果位于 `dist/YGODIY/YGODIY.exe`，分享时需要保留整个 `dist/YGODIY` 文件夹。

```powershell
.\.venv\Scripts\python.exe scripts/build.py
```

资源包支持离线导入，也可以从已有程序目录导入。离线卡库和 MDPro3 的准备方式、构建排错及资源授权说明见 [构建说明](docs/构建说明.md)。模块结构见 [源码说明](docs/源码说明.md)。

## 快速上手

### 第一次用积木

1. 打开顶部模式下拉框，在「DIY 工作台」下方选择 **积木入门**。
2. 在「决斗规则」看卡面、场地和回合图解，再到「入门练习」找「第一张卡 · 让自己抽一张」。课程里的配图可以打开原图。
3. 打开「练习桌」，选抽卡题。在中栏放入「会发动的效果」，点它的「处理」槽，再双击左栏的「抽卡」。点「核对练习」会提示下一步。「看搭法」可以对照参考树。
4. 遇到陌生积木，在「积木图鉴」按中文名称或引擎接口搜索。在工作台选中一块按 **F1** 也能直达它的说明。练习桌提供四道独立练习，做好的正式卡片在工作台保存。

离线手册包含 14 节入门课程、21 节决斗规则，以及 12 类、334 种积木的逐块用法。[查看工作台抽卡示例图](diy_workbench/handbook/图/编辑器.png)

### 做一张卡面

1. 在窗口顶部的下拉框选择模式，比如 `OCG/TCG`。
2. 在右侧填写卡名、类型、属性、攻守和效果文字，导入卡图。
3. 左侧的「卡包」「卡片」列表用来管理多张卡。
4. 需要印刷时，在图片导出对话框勾选「印刷出血」，程序会按成品卡高 86 mm 换算，在四边各延伸 3 mm 并附裁切标记。

### 写效果并装进 MDPro3

1. 模式切换到 **DIY 工作台**，选中一张卡。
2. 在「效果」页拼积木，程序会生成效果文字。积木表达不了的效果，可以到「脚本」页手写 Lua，或者点「让伊格尼斯写」。
3. 点「在测试沙盒里检查这张卡」，确认效果能运行。
4. 到「卡包」页检查卡号、字段和指示物，再点「导出并装进 MDPro3」。要保存文件，点「另存 .ypk / .cdb…」。已有数据库可以从同一页的「导入卡片或卡包…」打开。
5. 想卸载或恢复卡包，到「已安装」页操作。

### 复制或导出卡片文字

- **OCG/TCG、超速决斗模式：** 点顶栏的「复制文字」复制当前卡；点旁边的小箭头可以导出 txt。
- **DIY 工作台：** 在「卡包」页点「导出文字」，可以导出这张卡或整个卡包。

导出格式：

```text
卡名
[怪兽|效果|调整] 电子界/风
[★3] 600/1000

效果文字
```

### 使用伊格尼斯

1. 点顶栏的「伊格尼斯」打开面板。
2. 在服务设置里选择服务商，填入你自己的 API Key。
3. 用文字描述想要的卡，比如「帮我设计一张从卡组检索的魔法卡」。
4. 查看它给出的修改，确认后应用；不满意可以撤销。

内置的服务商有 DeepSeek、Grok、Kimi、通义千问、硅基流动、智谱 GLM、OpenAI、Claude 和本地 Ollama，也可以填自定义服务。使用云端服务的费用由服务商收取；开始对话后，你的卡片内容和对话会发送给所选的服务商。API Key 用 Windows 的数据保护接口加密后保存在本机。

## 目前的限制

- 中文效果积木适合从零设计。需要逐函数复现实卡时，可用整卡脚本积木。支持范围和逐卡核对结果见 [积木说明](blocks/README.md#本机语料核对)。
- 通过测试沙盒不代表效果完全正确，重要的卡请在实际对局里再试一次。
- 伊格尼斯写的内容要自己核对，尤其是效果文字和裁定细节。
- Windows 提供独立程序构建流程。macOS 可从源码运行编辑器，MDPro3 实盘沙盒依赖 Windows 版引擎。
